# AllumStuff

Плагин базовых механик для сервера **Allum: GO!**: авторестарт с голосованием, локальный/глобальный
чат с пузырями, пропуск ночи и персональные теги игроков.

## ⚠️ Важно: как получить .jar

В окружении, где собирался этот проект, нет доступа к интернету и Maven — поэтому я не могу
скомпилировать .jar прямо здесь. Вместо этого в проект уже добавлен файл
`.github/workflows/build.yml`, который **бесплатно соберёт готовый .jar в облаке GitHub**
за вас, без единой команды в терминале.

### Шаги (5 минут, без программирования):

1. Зайдите на [github.com](https://github.com) и создайте бесплатный аккаунт (если ещё нет).
2. Нажмите **New repository**, дайте любое имя (например, `allum-stuff`), нажмите **Create repository**.
3. На странице репозитория нажмите **uploading an existing file** (или "Add file → Upload files")
   и перетащите **всю папку проекта целиком** (структура папок сохранится).
4. Нажмите **Commit changes**.
5. Откройте вкладку **Actions** вверху репозитория — сборка запустится автоматически
   (займёт около минуты).
6. Когда сборка завершится (зелёная галочка), откройте её и внизу найдите раздел **Artifacts** →
   скачайте `AllumStuff` — это zip-архив с готовым `AllumStuff.jar` внутри.

**Если сборка выдаст красный крестик** — скорее всего, не подошла версия Paper API в `pom.xml`
(сервер называет себя `26.2`, а точное название версии в репозитории Maven может отличаться).
Откройте `pom.xml`, найдите строку `<paper.version>26.2-R0.1-SNAPSHOT</paper.version>`, зайдите на
https://repo.papermc.io/service/rest/repository/browse/maven-public/io/papermc/paper/paper-api/
и подставьте точную существующую версию — сборка запустится заново автоматически.

## Установка

1. Положите `AllumStuff.jar` в папку `plugins/` вашего сервера.
2. Перезапустите сервер один раз — создастся папка `plugins/AllumStuff/` с `config.yml` и `titles.yml`.
3. Настройте `config.yml` при желании (см. ниже), затем `/allumstuff reload` или рестарт.

## Функции

### 1. Авторестарт (каждые 3 часа)
- За 5 минут до рестарта — сообщение в чат с предложением проголосовать `/rskip`.
- Если против проголосует ≥ половины онлайна — рестарт откладывается на 1 час.
- Если сервер пуст в момент проверки — рестарт происходит тихо, без голосования.
- Сама остановка сервера — безопасный `Bukkit.shutdown()` (как обычный `/stop`, с сохранением мира).

**Про автоматический перезапуск процесса:** плагин лишь останавливает сервер. Поднимет ли он
процесс заново — зависит от того, чем вы его запускаете. Если это хостинг-панель (Pterodactyl,
AMP и т.п.) — она обычно делает это сама. Если запускаете вручную скриптом — используйте
цикл-обёртку, например:
```bash
#!/bin/bash
while true; do
  java -Xmx4G -jar paper.jar --nogui
  echo "Сервер остановлен, перезапуск через 5 секунд..."
  sleep 5
done
```
Сохраните это как `start.sh` и запускайте сервер через него — тогда после каждого `/stop`
(в том числе от плагина) сервер поднимется заново автоматически.

### 2. Чат: локальный/глобальный + пузыри
- Обычное сообщение — видно в радиусе 150 блоков (тег `[L]`, жёлтый).
- Сообщение с `!` в начале — видно всем на сервере (тег `[G]`, зелёный), сам `!` из текста убирается.
- Текст сообщения всегда белый.
- Над головой пишущего на несколько секунд появляется пузырь с текстом сообщения (настраивается
  в `config.yml`, работает и для игроков с Bedrock).

### 3. Пропуск ночи
- Как только кто-то лёг спать — сообщение в чат.
- Через 6 секунд (настраивается) ночь пропускается автоматически, если никто не написал `/nskip`.
- `/nskip` отменяет текущий пропуск.

### 4. Персональные теги (`/title`)
- `/title <текст>` — устанавливает тег перед своим ником в чате, с поддержкой цветовых кодов через `&`
  (например `/title &6[Легенда]`).
- `/title off` — снимает тег.
- Тег сохраняется между заходами на сервер.

## Команды и права

| Команда | Право | По умолчанию |
|---|---|---|
| `/rskip` | `allumstuff.rskip` | у всех |
| `/nskip` | `allumstuff.nskip` | у всех |
| `/title <текст\|off>` | `allumstuff.title` | у всех |
| `/allumstuff reload` | `allumstuff.admin` | у оператора (op) |

## Конфигурация

Все параметры (интервал рестарта, радиус чата, задержка сна, лимит длины тега, тексты сообщений)
находятся в `plugins/AllumStuff/config.yml` с комментариями на русском.
